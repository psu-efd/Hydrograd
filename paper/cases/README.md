# Cases of the Hydrograd v2.0 paper

Input files of the cases used in the model description paper (Liu, *Hydrograd v2.0*, GMD, in preparation). Each folder holds the SRH-2D files (`.srhgeom`, `.srhhydro`, `.srhmat`), the `run_control.json`, and, where the case needs them, the initial condition, the truth (observation) file and `.xys` time series. Outputs are not stored; the figure scripts in `paper/` copy a case into a scratch folder before running it.

**Copy a folder before running it in place:** a forward run writes `forward_simulation_solution_truth.json`, which would overwrite the truth file of the example.

| Folder | Paper | Case | Origin |
|---|---|---|---|
| `channel_bump_transcritical/` | Sect. 4.1, Fig. 3d–e | Transcritical flow over a bump, 200 cells; `analytical_solution_from_FullSWOF.dat` is the reference solution | Hydrograd.jl example `forward_simulation/oneD_channel_with_bump` |
| `savannah_river_steady/` | Sect. 4.2, Figs. 2, 4 | Savannah River reach, 1,306 cells, five roughness zones, steady forward run and comparison with SRH-2D | Hydrograd.jl example `forward_simulation/Savannah_River` |
| `savannah_river_inversion/` | Sect. 4.2, Fig. 5 | Manning's n inversion on the same reach (truth file with the target roughness) | Hydrograd.jl example `inversion/ManningN_inversion/Savannah_River` |
| `../data/fig06_steady_ude/` | Sect. 4.4, Fig. 6 | Closure learning n = N(h) on the bump channel: `truth/`, `steady/` and `transient/` training folders | written by `fig06_steady_ude.py` |
| `hydrograph_inversion/` | Sect. 4.5, Fig. 7 | Compound-channel valley, 500 cells: `truth/` (hydrograph every 5 min, SSP-RK3) and `inv/` (inversion model, 15 min knots, backward Euler) | written by `prep_hydrograph_inversion.py` (`hydrograd.io.synthetic.write_channel_case`) |
| `savannah_river_unsteady/` | Sect. 4.6, Fig. 8 | Savannah River reach with the 6 h flood hydrograph `flood.xys`, unsteady roughness calibration | `benchmarks/validation/savannah_unsteady_inversion.py` from the steady case |
| `flood_wave/` | Fig. S1 | Flood wave through a compound channel, 16,000 cells: `base_flow/` spin-up and `flood_wave/` with the inflow and stage series | written by `prep_flood_wave.py` |

The remaining cases of the paper are generated by their scripts at run time with `hydrograd.io.synthetic.write_channel_case`: the dam breaks, the lake at rest and the subcritical bump of Sect. 4.1 (`fig03_verification.py`), the vegetated channel of Sect. 4.7 (`fig09_vegetation.py`), and the scaling channels of Sect. 4.8 (`perf_*.py`, up to 512,000 cells).

To run a case by hand:

```bash
cp -r paper/cases/savannah_river_steady /tmp/savannah && cd /tmp/savannah && hydrograd run
```
